# DressWell_Supabase

Hoy estuve realizando un pequeño formulario conectado a Supabase, el cual funciona como sistema de base de datos y utiliza PostgreSQL como motor de base de datos. La información ingresada por los usuarios puede ser almacenada y visualizada directamente desde Supabase. Además, el proyecto fue desplegado en Render para que pueda ejecutarse y ser accesible desde la web.

Este pequeño proyecto consiste en permitir que los usuarios puedan realizar solicitudes de productos, especialmente relacionados con el área de la moda. De esta manera, el formulario facilita el registro de las solicitudes y permite gestionar la información de los productos de una manera más organizada.
